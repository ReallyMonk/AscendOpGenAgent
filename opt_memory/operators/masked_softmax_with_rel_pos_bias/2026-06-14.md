## Iter 1: fused-input softmax with DataCopyPad

- **改动**：Implemented AscendC kernel with: 1) Pre-fuse qk+bias and mask on Python side as -inf for masked positions; 2) Single VECIN/VECOUT queue with DataCopyPad for GM↔UB transfer; 3) Softmax via fp32 TBuf with scalar max/sum loops; 4) Cast fp16↔fp32 with PipeBarrier. Key fix: DataCopyPad (not DataCopy) required for CANN 8.5.0.
- **性能**：0.01 TFLOPS，利用率 0.003%
- **状态**：✅通过
- **洞察**：DataCopyPad required for CANN 8.5.0, plain DataCopy produces all-zero output. Multi-VECIN-queue fails TQue depth assertion. Pre-fusing inputs on Python side enables single-queue design. Scalar loops on TBuf limit performance to ~0.01 TFLOPS but prove correctness.
