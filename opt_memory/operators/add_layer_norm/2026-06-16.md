## Iter 2: ReduceSum vectorized reduction

- **改动**：Replaced O(N) scalar reduction loop with AscendC ReduceSum vectorized reduction; used separate reduceResult buffer (256 floats) as dst to avoid self-alias corruption; castBuf reused as ReduceSum src workspace with pre-copy from computeBuf
- **性能**：0.42 TFLOPS，利用率 0.66%
- **状态**：✅通过
- **洞察**：ReduceSum 向量化归约将 O(N) 标量循环替换为硬件向量指令，S4 从 15.7ms 降至 0.56ms (28x 提升)；关键技巧：dst≠src 避免自别名破坏源数据
