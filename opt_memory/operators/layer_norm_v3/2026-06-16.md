## Iter 1: blockM tuning: 128→1024

- **改动**：Increased DEFAULT_BLOCK_M from 128 to 1024 to reduce kernel launch overhead for M=524288
- **性能**：0.004 TFLOPS，利用率 3.0%
- **状态**：⚠️部分改善
- **洞察**：BlockM increase had negligible effect: bottleneck is scalar sum loop (1024 iter/row) and sequential DMA per row, not kernel launch overhead
