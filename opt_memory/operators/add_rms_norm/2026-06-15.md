## Iter 2: tbuf_direct_copy_reducesum

- **改动**：Replaced TQue (AllocTensor/EnQue/DeQue/FreeTensor per row) with direct DataCopy on TBuf (VECCALC). Added ReduceSum for vectorized sum-of-squares. Eliminated ~32K TQue operations for 4096 rows, reducing per-row overhead dramatically.
- **性能**：0.338 TFLOPS，利用率 1.09%
- **状态**：✅通过
- **洞察**：TQue per-row overhead (alloc/enque/deque/free) is the dominant bottleneck for element-wise fusion ops with many rows. Using TBuf+DataCopy eliminates ~4 TQue operations per row per buffer, giving 22.8x speedup over the TQue baseline. Speedup vs PyTorch: 2.44x.

## Iter 3: tune_blockM_64

- **改动**：Tuned blockM from 128 to 64 for better load balancing. With 64 blocks across 32 cores, each core gets 2 tasks. Better utilization for small M values.
- **性能**：0.343 TFLOPS，利用率 1.11%
- **状态**：✅通过
- **洞察**：blockM=64 provides equivalent performance to blockM=128 for M=4096 (2.50x vs 2.44x speedup) but enables better load balancing for smaller M values (e.g., M=1024 uses 16 cores vs 8).
